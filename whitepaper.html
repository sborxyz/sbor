SBOR · STANDARD BITCOIN OFFERED RATE

A Reference Rate for Bitcoin-Backed Credit

The SBOR white paper, version 1 · Guy Zaniratto

Credit is priced against reference rates. A dollar loan says "SOFR plus a spread," and anyone can check the first half. Loans against bitcoin are priced venue by venue, each at its own rate, so a borrower, a fund or an AI agent cannot tell how an offer compares with the market. This paper proposes a reference rate for bitcoin-backed credit: a daily fixing read directly from lending contract state, one borrow and one supply rate built from every eligible market, weighted by size, with every input shown, posted on-chain where contracts can read it, and never rewritten. It sets out what such a rate must be, how the Standard Bitcoin Offered Rate (SBOR) computes it, the rules learned by running it, and what becomes possible once lenders and borrowers use the same rate.

Stamped on-chain

The paper itself is not on-chain. Its fingerprint is. The SHA-256 below was posted on each chain listed, and each block's time is the date it was stamped. Any change to the PDF, even one character, gives a different hash. Later versions get their own stamp, and this one stays.

Stamps are posted on publication day.

Check it yourself

Download the PDF and run shasum -a 256 SBOR_White_Paper_v1.pdf. The result must equal the hash above and the hash in every transaction. On Stacks, the contract sbor-whitepaper-v1 holds the hash as a constant anyone can read. On Bitcoin, the OP_RETURN reads "SBOR WP1 " followed by the hash. An OpenTimestamps proof anchors the same hash in Bitcoin a second way. The full record is in whitepaper-stamps.json.
